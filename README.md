# Smart Compass

Smart Compass is a wearable compass in development. It uses LoRa to find
friends and a spiral of LEDs to show directions and light patterns.

## Build

Use the 200 mm carrier build. The carrier PCB connects the docked modules.
The fixed harness uses locking plugs and service slack. The build has USB-C
charging and a removable protected battery.

- [Print kit and previews](https://blinkystitt.github.io/smart-compass-v0/#rev-a)
- [Print and first-fit instructions](designs/carrier/printing.md)
- [Assembly, connector pins and wire slack](designs/carrier/assembly.md)
- [Carrier PCB and build checks](designs/carrier/README.md)
- [USB-C charging and wall power](designs/carrier/wall-power-pd60.md)

Check the harness fit, battery service, weight and runtime on the first
assembled unit.
