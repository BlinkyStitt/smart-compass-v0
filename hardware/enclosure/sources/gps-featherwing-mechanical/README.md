# Original Adafruit GPS mechanical source

The original Adafruit 3133 STEP, upstream README and MIT license are unchanged.
The index records their source revision, URLs, byte counts and SHA-256 values.
The electrical Eagle files have their own license in `../gps-featherwing`.

The STEP has 55 solids. Its largest solid is the nominal 50.8 × 22.86 × 1.57 mm
PCB. The complete module is 6.62 mm high. The board datum is its lower-left
outline corner, viewed from the component side. All 56 source through-holes
register with this PCB in the retained recovery inspection. This checks
mechanical registration; it does not establish electrical revision equivalence
or dimensions of a supplied module. The model does not include a backup cell.
